
## The blueprint theme
Cool, analytical palette. Tokens at the top of styles.css:
  --paper  #EEF2F7  cool porcelain background
  --ink    #0E1A2B  deep navy (text + hero/footer)
  --amber  #2B5FE3  electric cobalt (primary accent — variable name kept for simplicity)
  --sage   #0E9AA6  teal (secondary)
  --gold   #F0653E  coral (warm contrast pop)
Change a token, the whole site follows. (The token names amber/sage/gold are
historical — they now hold cobalt/teal/coral.)
